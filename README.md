# movie_tracker

Веб-приложение, позволяющее пользователям просматривать каталог фильмов и выставлять им оценки.
На основе оценок пользователей рассчитывается средний рейтинг каждого фильма,
а также предоставляется возможность поиска фильмов по жанру и рейтингу.
